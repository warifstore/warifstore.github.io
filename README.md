# متجر وارف — دليل الإعداد

موقع بصفحة واحدة لعرض المنتجات. بدون سلة أو دفع إلكتروني — الزبونة تتصفح
وترسل رسالة على انستغرام للطلب. المنتجات تُدار من شيت Google Sheets، فأي
شخص بالفريق يقدر يضيف أو يعدّل منتج بدون أي برمجة.

---

## ١. رفع الموقع على GitHub Pages (مرة وحدة، ٥ دقائق تقريبًا)

1. أنشئي مستودع (repo) جديد على GitHub، مثلاً `warif-store`.
2. ارفعي ملف `index.html` في جذر المستودع.
3. من **Settings → Pages**، اختاري الفرع `main` والمجلد الرئيسي كمصدر.
4. GitHub بيعطيك رابط مثل `https://yourusername.github.io/warif-store/`
   — هذا رابط موقعك المباشر.

---

## ٢. إنشاء شيت المنتجات (مرة وحدة، دقيقتين تقريبًا)

1. افتحي [Google Sheets](https://sheets.google.com) وأنشئي شيت جديد.
2. في الصف الأول، ضيفي هذه العناوين بالضبط (بالإنجليزي، لأن الكود يقرأها):

   | name | image | description |
   |------|-------|-------------|

   ملاحظة: تم إلغاء عمود السعر عن قصد — الأسعار ما تظهر بالموقع، وتُذكر فقط
   عند تواصل الزبونة عبر رسائل انستغرام.

3. ضيفي صف لكل منتج. مثال:

   | name | image | description |
   |------|-------|-------------|
   | توب كتان أوفرسايز | https://i.imgur.com/abc123.jpg | قصة واسعة، قماش كتان طبيعي. |

4. **نشر الشيت على الويب:**
   - من القائمة: `File → Share → Publish to web`
   - تحت "Link"، اختاري تبويب الشيت الصحيح (مو "Entire document") واختاري صيغة **CSV**.
   - اضغطي **Publish** وانسخي الرابط اللي يظهر لك.

5. افتحي ملف `index.html`، ودوّري على هذا السطر بالأعلى:

   ```js
   const PRODUCTS_CSV_URL = "";
   ```

   والصقي رابطك بين علامتي التنصيص:

   ```js
   const PRODUCTS_CSV_URL = "https://docs.google.com/spreadsheets/d/e/xxxxx/pub?output=csv";
   ```

6. حددي كذلك حساب انستغرام بالسطر اللي بعده:

   ```js
   const INSTAGRAM_HANDLE = "warifstore";
   ```

7. ارفعي ملف `index.html` المحدّث على GitHub مرة ثانية — وخلاص، الموقع صار شغال.

بعد ما تربطين الشيت، الأمثلة التوضيحية الموجودة حاليًا بتختفي تلقائيًا
وتنعوض بمنتجاتك الحقيقية.

---

## ٣. إضافة منتج جديد (هذا اللي تسوّيه الزميلات — بدون أي برمجة)

فقط افتحي شيت Google Sheets وضيفي صف جديد:

- **name** — اسم المنتج، مثل `أقراط دائرية ذهبية`
- **image** — رابط مباشر لصورة المنتج (شوفي تحت كيف تحصلين عليه)
- **description** — جملة قصيرة، اختيارية بس تفضّل

الموقع يتحقق من الشيت كل ما حد يفتح الصفحة — ما فيه شي تنشرينه أو تزامنينه.
احفظي الصف، والمنتج يظهر خلال ثوانٍ.

لحذف منتج، احذفي صفه. لإعادة الترتيب، اسحبي الصفوف لفوق أو تحت بالشيت.

### الحصول على رابط صورة

أي طريقة من هذي تشتغل — بس لازم يكون الرابط مباشر لصورة، مو لصفحة ويب:

- **Imgur** (الأسهل): روحي [imgur.com/upload](https://imgur.com/upload)، ارفعي
  الصورة، ثم كليك يمين على الصورة المرفوعة واختاري "Copy image address".
- **Google Drive**: ارفعي الصورة، كليك يمين → Share → خليها "Anyone with the
  link"، وبعدين حوّلي الرابط لصيغة مباشرة:
  `https://drive.google.com/uc?export=view&id=FILE_ID_HERE`
  (الجزء `FILE_ID_HERE` هو الرمز الطويل الموجود بالرابط الأصلي).

## ملاحظات

- زر "اطلبي عبر الرسائل" يفتح رسالة انستغرام مباشرة (`ig.me/m/اسم_الحساب`).
  يشتغل تلقائيًا لمعظم الحسابات؛ إذا ما اشتغل لأحد، تقدر توصل لحسابك
  وترسل رسالة عادية.
- ما فيه دفع إلكتروني بالموقع — هو "لوك بوك" للعرض فقط، مو نظام شراء،
  وهذا بالضبط اللي طلبتيه بالبداية.
- إذا حبيتي مستقبلاً تضيفين دفع حقيقي، نفس التصميم يقدر يترابط مع
  Shopify Buy Button أو Stripe Payment Links بدون إعادة بناء الموقع من الصفر.
